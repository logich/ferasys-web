# Legacy Logo Assets

These SVG logos were generated procedurally in an earlier brand-package commit
and were sidelined on 2026-05-27 because they aren't production-quality:

- `logo-primary.svg` — Pentagon "wolf head" with floating triangle ears and
  zigzag snout; doesn't read as a wolf. Tagline + Arial wordmark baked in.
  Dark navy background filled in the primary mark itself.
- `logo-mark.svg` — Same flawed wolf shape, plus a stray network glyph
  positioned via fixed coordinates that doesn't move with the head transform.
- `logo-horizontal.svg` — Same wolf paired with Arial wordmark and tagline,
  inconsistent with the site's actual brand fonts (Lastica, Anonymous Pro).
- `logo-monochrome.svg` — Same underlying shapes.

The canonical brand mark is now `wolf.jpg` / `brand/raster/wolf-mark-*.png`.
Auto-traced vector candidates live in `brand/raster/wolf-mark-*.svg`. None of
them is a substitute for a properly-designed vector — that's a designer
follow-up.
